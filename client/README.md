# Mortgage Calculator client

The client is a React application built with Vite and styled with Tailwind CSS. It provides combined, rates-only, and calculator-only views and communicates with the Express API at `http://localhost:3001`.

From this directory:

```bash
npm install
npm run dev
```

Use `npm run lint` to check the source and `npm run build` to create a production bundle. Project-wide setup, architecture, API, and testing guidance is maintained in the repository root documentation.
